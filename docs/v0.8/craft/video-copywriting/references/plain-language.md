# Plain language for video copy

Plain language for video copy is writing that viewers anywhere understand at a glance: short sentences, common verbs, unambiguous numbers and dates, and no idioms that only work in one culture. It applies to titles, captions and narration for any audience that includes non-native speakers or people reading fast on a phone.

## Reading level targets

Reading level targets set how simple copy must be.

**Target: Grade 7 or below for global compositions.**

Grade 7 (age 12–13) reading level is the threshold at which:
- Non-native English speakers at intermediate level can follow comfortably
- People reading on a small screen in a distracted environment can process the message
- The content is accessible across all education levels without losing intelligence

**Reading level by audience:**

| Audience | Target grade | Notes |
|---|---|---|
| Consumer / mass market | 5–7 | TikTok, Instagram, YouTube Shorts |
| Professional / B2B | 7–9 | LinkedIn, product marketing |
| Technical / developer | 9–11 | Acceptable, audience expects precision |
| Healthcare / legal / financial | 6–8 | Regulatory guidance often requires plain language |
| International / global | 5–6 | Non-native speakers need lower complexity |
| Children's content | 2–4 | Explicit vocabulary control required |

**How to estimate reading level without a tool:**
- Count syllables per word. Average above 2.5 = too complex.
- Count words per sentence. Average above 14 = too complex.
- Count sentences with passive voice. Any = needs review.
- Count abstract nouns. More than 2 per sentence = too complex.

## Sentence construction rules

Sentence construction rules keep each line quick to parse.

### Rule 1: Sentence Length

| Use case | Max words | Ideal words |
|---|---|---|
| Hero headline | 7 | 3–5 |
| Subheadline | 12 | 7–9 |
| Body sentence | 18 | 10–14 |
| Caption (spoken) | 12 | 7–10 |
| CTA | 4 | 2–3 |

When a sentence exceeds the maximum: split it into two sentences. Do not compress, split.

### Rule 2: Sentence Structure

Always: **Subject → Verb → Object**

```
Subject:  Who is doing it?
Verb:     What are they doing?
Object:   What are they doing it to?
```

Every deviation from this structure costs cognitive effort. Every cognitive effort is a viewer lost.

```
✓ "Your team ships faster."
✗ "Shipping speed is improved for your team."

✓ "We built this for real-world teams."
✗ "Built for real-world teams by our engineers."

✓ "Find what you need in seconds."
✗ "Search functionality enables rapid discovery."
```

### Rule 3: Verb Choice

Choose verbs that describe physical, visible action. Avoid nominalization (turning verbs into nouns).

| Nominalization (avoid) | Active verb (use) |
|---|---|
| "make a decision" | "decide" |
| "give a recommendation" | "recommend" |
| "provide an analysis" | "analyze" |
| "offer assistance" | "help" |
| "conduct a review" | "review" |
| "enable the improvement of" | "improve" |
| "facilitate collaboration" | "collaborate" |
| "achieve optimization" | "optimize" |

### Rule 4: Paragraph / Stanza Length

For composition copy, there are no paragraphs. Each visual beat gets one sentence, or one idea. Multiple sentences on screen simultaneously compete.

**Maximum on-screen text at any moment:**
- 9:16 (phone): 1 headline + 1 supporting line
- 1:1 (square): 1 headline + 2 supporting lines
- 16:9 (landscape): 1 headline + 3 supporting lines max

## Accessible verbs

Accessible verbs are the ones intermediate English speakers understand everywhere. Use them over complex alternatives.

```
add      allow    ask      be       begin    bring    build
buy      call     can      change   check    choose   close
come     connect  create   cut      do       draw     drive
end      feel     find     fix      get      give     go
grow     have     help     hold     keep     know     launch
lead     learn    let      like     link     listen   live
look     lose     love     make     manage   meet     move
need     open     pay      plan     put      read     reach
remove   run      save     see      send     set      share
show     start    stay     stop     take     teach    test
think    try      turn     use      want     win      work
write
```

**Note:** Phrasal verbs (set up, look into, find out, work out) are often clearer than their formal equivalents, especially for non-native speakers who learn phrasal verbs as whole units.

## Number formatting for global audiences

Number formatting for global audiences avoids separators and date orders that differ by region.

### Numerals vs. Words

| Number | Written form | When to use words |
|---|---|---|
| 1–10 | one, two, three... | Flowing text and captions only |
| 11+ | 11, 12, 13... | Always use numerals in compositions |
| Round thousands | 1,000 / 1K | Prefer K notation in display |
| Millions | 2.4M | Always in display contexts |
| Billions | 1.2B | Always in display contexts |
| Percentages | 87% (not eighty-seven percent) | Always numerals with % symbol |
| Currency | $2.4M / €1.2B | Numeral + symbol + magnitude |

### Comma vs. Period in Large Numbers

This is a cultural minefield. Different regions use different separators:
- USA/UK: 1,000,000 (comma as thousands separator, period as decimal)
- Europe: 1.000.000 (period as thousands separator, comma as decimal)
- India: 10,00,000 (lakh system)

**For global compositions:** Use the K/M/B shorthand to avoid the separator problem entirely.
```
✓ "2.4M users"        (universally understood)
✗ "2,400,000 users"   (ambiguous globally)
✗ "2.400.000 users"   (wrong in USA/UK contexts)
```

### Time

| Format | Use | Avoid |
|---|---|---|
| "3 hours" | General time duration | "180 minutes" (unnecessary complexity) |
| "2 minutes" | Completion time | "120 seconds" (unless under 2 minutes) |
| "6 days a year" | Impact time | "0.016 years" (meaningless) |
| "10:00 AM / 10:00 PM" | Specific times | "10:00" without AM/PM (ambiguous) |
| "Monday, June 3" | Dates | "6/3" or "3/6" (ambiguous globally) |

## Cultural neutrality

Cultural neutrality means avoiding references that only one culture reads correctly.

### Sports Metaphors
Almost all sports metaphors fail global audiences. Different sports have completely different cultural weight in different regions.

| Metaphor | Problem | Replacement |
|---|---|---|
| "home run" | Baseball is not global | "big success" |
| "touchdown" | American football is regional | "win" |
| "hat trick" | Cricket/soccer, regional usage | "three wins" |
| "kick off" | Soccer, acceptable, but avoid | "start" |
| "par for the course" | Golf, niche | "normal" |
| "on the front foot" | Cricket | "ahead" |

### Seasonal References
Seasons are inverted in the Southern Hemisphere, and irrelevant in tropical regions.

| Fail | Replacement |
|---|---|
| "Spring cleaning" | "Fresh start" |
| "January resolution" | "New goal" |
| "Summer momentum" | "Growth period" |
| "Winter is coming" | Delete (cultural reference) |
| "Q4 push" | Acceptable in business context, clarify if needed |

### Cultural Hierarchy / Power References
Avoid language that implies cultural hierarchy.

| Avoid | Why | Use instead |
|---|---|---|
| "Western standards" | Implies non-Western = lower | "global standards" |
| "civilized" | Colonial connotation | "modern" |
| "developed world" | Offensive to many | "high-income countries" or name them |
| "third world" | Outdated, offensive | "emerging markets" or name them |
| "first world problems" | Dismissive of real hardship | Delete |

## Accessibility beyond language

Accessibility beyond language covers cognitive, visual and audio needs.

### Cognitive Accessibility

For viewers with reading difficulties, attention differences, or cognitive load from context:

- **One idea at a time:** Never show two competing ideas simultaneously
- **Consistent terminology:** Use the same word for the same thing. Don't say "platform" then "tool" then "system" for the same product.
- **Predictable structure:** If a composition has 3 stat cards, they should all look and behave the same way
- **No blinking text:** Flashing text (more than 3 times per second) is a seizure trigger, never use
- **High contrast:** Minimum 4.5:1 contrast ratio between text and background for all copy

### Visual Accessibility

- **Color-blind safe:** Never use color alone to convey meaning in copy. A stat labeled in red for "bad" and green for "good" fails for ~8% of men globally.
- **Size minimums** (see the platform-formats orientation reference):
  - 9:16: headline ≥ 48px, body ≥ 28px, captions ≥ 32px
  - 1:1: headline ≥ 40px, body ≥ 24px
  - 16:9: headline ≥ 56px, body ≥ 28px
- **Line length:** 45–75 characters per line for optimal readability. Below 30 is too choppy; above 80 is too wide for comfortable reading.

### Audio Accessibility (9:16 Critical)

For vertical compositions on TikTok/Reels/Shorts, 50–70% of viewers watch with audio off.

**The mute test:** Remove all audio from the composition. Does every idea still communicate completely through visuals and captions? If not, the composition fails 50% of its audience.

**Caption requirements for 9:16:**
- Maximum 2 lines of caption at any time
- Maximum 10 words per line
- Line break at natural speech pause (comma, end of clause), not mid-phrase
- Caption timing: appears 0.1s before the word is spoken; disappears 0.2s after
- Caption contrast: white text on dark semi-transparent background (or black text on light)

## Plain language editing checklist

The plain language editing checklist: run each line through it before building scenes.

**One pass per line:**
```
□ Can I remove any word without changing the meaning? → Remove it.
□ Is there a shorter word that means the same thing? → Use it.
□ Is this the most direct way to say this? → If not, rewrite.
□ Does this treat the viewer as an equal? → If not, rewrite.
□ Does this work for a viewer who knows nothing about the category? → If not, add context or simplify.
□ Could this be misunderstood? → If yes, rewrite.
□ Is there a number that could replace an abstract claim? → Use the number.
□ Is there a specific example that could replace a general statement? → Use the example.
```

**The final test:**
Read the full copy out loud at normal speaking pace. Time it. If it takes longer than 70% of the composition duration to read, it is too much copy. Cut until 70% or below.
